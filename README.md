# E-Commerce Sales & Revenue Analytics (Case 6)

## 📌 Описание проекта
Практический кейс по анализу данных интернет-магазина. Проект направлен на объединение информации о заказах и каталоге товаров, вычисление ключевых бизнес-метрик (выручки), а также отбор наиболее прибыльных товаров в разрезе категорий.

## 🛠 Используемый стек
- **Python 3.x**
- **Pandas**

## 💡 Выполненные задачи
1. **Слияние данных (`pd.merge`)**: Объединение таблицы заказов (`orders`) со справочником товаров (`catalog`) по ключу `item` с использованием типа связи `left join` для сохранения полного массива заказов.
2. **Расчет выручки**: Вычисление суммарной стоимости каждого заказа (`total_sum = quantity * price`).
3. **Фильтрация и сегментация**: Выделение целевой категории `'Аксессуары'` с пороговым значением выручки более 10 000 ₽.
4. **Агрегация результатов**: Расчет итоговой выручки по отфильтрованному сегменту с помощью `.sum()`.

## 📊 Результаты анализа
После применения логики фильтрации в итоговую выборку попали следующие позиции:
- **Мышь**: 10 шт. × 1 500 ₽ = **15 000 ₽**
- **Клавиатура**: 5 шт. × 3 000 ₽ = **15 000 ₽**

**Итоговая выручка по категории «Аксессуары» (продажи > 10k ₽):** `30 000 ₽`
